10 Most-Asked Python Lists Interview Questions

Prepare effectively for your next Python Lists interview with these commonly asked questions and model answers.

1. What is the difference between a List and a Tuple?

The primary difference is mutability. Lists are mutable (you can change, add, or remove elements), whereas tuples are immutable. Because of this, tuples are generally faster and can be used as keys in dictionaries, while lists cannot.

2. How are Python lists stored in memory?

Python lists are dynamic arrays. They store references to objects rather than the objects themselves. When a list grows beyond its allocated capacity, Python allocates a larger chunk of memory and copies the references over.

3. What is List Comprehension and how do you use it?

List comprehension is a concise way to create lists. It consists of brackets containing an expression followed by a for clause. For example: [x**2 for x in range(5)] creates a list of squares.

4. What is the time complexity of common List operations?

In Big O notation: Accessing an element is O(1), appending an element is O(1) (amortized), but inserting or deleting at the beginning/middle is O(n) because subsequent elements must be shifted.

5. What is the difference between append() and extend()?

append() adds a single element to the end of the list. extend() iterates over an iterable (like another list) and adds each element individually to the end.

6. How do you remove duplicates from a list?

The most common way is to convert the list to a set and back to a list: list(set(my_list)). Note that this does not preserve the original order of elements.

7. What is List Slicing?

Slicing allows you to access a range of elements using the syntax list[start:stop:step]. For example, my_list[::-1] is a common idiom used to reverse a list.

8. What is the difference between shallow copy and deep copy?

A shallow copy creates a new list object but copies references to the original nested objects. A deep copy (using the copy module) recursively creates copies of all objects found in the original, making it truly independent.

9. How does the sort() method differ from the sorted() function?

list.sort() sorts the list in-place and returns None. The sorted(list) function returns a new sorted list, leaving the original list unchanged.

10. Can a Python list contain different data types?

Yes, Python lists are heterogeneous. Since they store references to objects, a single list can contain a mix of integers, strings, objects, and even other lists.
