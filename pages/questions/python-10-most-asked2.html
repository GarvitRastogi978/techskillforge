💻 10 Most-Asked Python Interview Questions (PART 2)

Prepare effectively for your next Python interview with these commonly asked questions and model answers.

1. What is the difference between Deep Copy and Shallow Copy?

A shallow copy creates a new object but fills it with references to the original nested objects. A deep copy creates a new object and recursively adds copies of the nested objects, ensuring that changes to the copy don't affect the original.

2. How is Memory Management handled in Python?

Python uses a private heap to manage memory. It employs a Reference Counter to track object usage and a Garbage Collector (using a cyclic-garbage-collection algorithm) to reclaim memory from objects that are no longer reachable.

3. What are Generators and how do they differ from Lists?

Generators are functions that return an iterable set of items one at a time using the yield keyword. Unlike lists, they are lazy-evaluated, meaning they save memory by not storing the entire sequence in RAM.

4. Explain the difference between *args and **kwargs.

*args allows a function to accept any number of positional arguments, which are stored in a tuple. **kwargs allows for any number of keyword arguments, which are stored in a dictionary.

5. What is Monkey Patching in Python?

Monkey patching refers to the practice of dynamic replacement of attributes, methods, or functions at runtime. It is often used in testing to replace complex objects with mock versions.

6. How do "Global Interpreter Lock" (GIL) affect multi-threading?

The GIL is a mutex that allows only one thread to execute Python bytecode at a time. This prevents true parallel execution of threads on multiple CPU cores, making Python's threading better for I/O-bound tasks than CPU-bound ones.

7. What is the use of 'self' in Python classes?

self represents the instance of the class. It allows the code to access the attributes and methods associated with that specific object, distinguishing them from local variables within the method.

8. What are List Comprehensions and why use them?

List comprehensions provide a concise way to create lists. They are generally faster and more readable than traditional for loops and append() calls for simple data transformations.

9. Explain Method Resolution Order (MRO).

MRO is the order in which Python searches for a method in a class hierarchy, especially in multiple inheritance scenarios. Python uses the C3 Linearization algorithm to determine this order.

10. What is the difference between @staticmethod and @classmethod?

A @classmethod takes cls as its first argument and can modify class state, while a @staticmethod takes no implicit first argument and behaves like a regular function belonging to the class's namespace.
