🛢️ 10 Most-Asked DBMS Interview Questions

Prepare effectively for your next DBMS interview with these commonly asked questions and model answers.

1. What is the difference between DBMS and RDBMS?

A DBMS (Database Management System) stores data as files and is generally for smaller datasets. An RDBMS (Relational DBMS) stores data in a tabular format (rows and columns) and enforces relationships between tables using keys, following Codd's rules.

2. Explain the ACID properties in DBMS.

ACID ensures reliable transaction processing: Atomicity (all or nothing), Consistency (valid data states), Isolation (transactions don't interfere), and Durability (committed data is permanent).

3. What is Normalization and why is it used?

Normalization is the process of organizing data to reduce redundancy and improve data integrity. It involves dividing large tables into smaller ones and defining relationships between them (e.g., 1NF, 2NF, 3NF, BCNF).

4. What are the different types of Joins?

Joins combine rows from two or more tables based on a related column. Common types include: Inner Join (matching records), Left Join (all left + matching right), Right Join (all right + matching left), and Full Join (all records from both).

5. Distinguish between Primary Key, Foreign Key, and Unique Key.

A Primary Key uniquely identifies a record and cannot be null. A Unique Key ensures uniqueness but allows one null value. A Foreign Key is a field in one table that links to the Primary Key of another, maintaining referential integrity.

6. What is a "Deadlock" and how is it handled?

A deadlock occurs when two or more transactions are waiting for each other to release locks, creating a cycle. It is handled through Deadlock Detection (killing one process), Deadlock Prevention, or Deadlock Avoidance algorithms.

7. What is the difference between DELETE, TRUNCATE, and DROP?

DELETE is a DML command that removes specific rows (can be rolled back). TRUNCATE is a DDL command that removes all rows (cannot be rolled back easily). DROP removes the entire table structure and data from the database.

8. What is an Index and what are its types?

An Index is a performance tuning technique that speeds up data retrieval. Common types include Clustered Index (reorders the way data is physically stored) and Non-Clustered Index (creates a separate structure to point to the data).

9. What is a View in DBMS?

A View is a virtual table based on the result-set of an SQL statement. It doesn't store data physically but provides a way to simplify complex queries or restrict access to specific columns for security.

10. What is the difference between a Stored Procedure and a Function?

A Function must return a value and can only use input parameters. A Stored Procedure may or may not return a value, can have both input/output parameters, and allows DML statements like INSERT or UPDATE.
