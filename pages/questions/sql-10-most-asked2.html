🛢️ 10 Most-Asked SQL Interview Questions (PART 2)

Prepare effectively for your next SQL interview with these commonly asked questions and model answers.

1. What is SQL and what is it used for?

SQL stands for Structured Query Language. It is the standard language used to communicate with, manage, and manipulate data within a Relational Database Management System (RDBMS).

2. What is the difference between DBMS and RDBMS?

A DBMS (Database Management System) manages data stored as files. An RDBMS (Relational DBMS) is a more advanced version that stores data in a structured tabular format (rows and columns) and uses keys to connect different tables.

3. What is a Primary Key?

A Primary Key is a unique identifier for each record in a table. It must contain unique values and cannot contain NULL values. Each table can have only one primary key.

4. What is a Foreign Key?

A Foreign Key is a field in one table that refers to the Primary Key in another table. It is used to create a link or relationship between the two tables.

5. What is the difference between DELETE and TRUNCATE?

DELETE is a DML command used to remove specific rows using a WHERE clause; it can be rolled back. TRUNCATE is a DDL command that removes all rows from a table; it is generally faster and cannot be rolled back easily.

6. What are the different types of Joins in SQL?

The main types are: Inner Join (matching values in both), Left Join (all from left + matches from right), Right Join (all from right + matches from left), and Full Join (all records when there is a match in either).

7. What is the purpose of the GROUP BY clause?

The GROUP BY clause is used to arrange identical data into groups. It is often used with aggregate functions like COUNT(), MAX(), MIN(), SUM(), and AVG().

8. What is the difference between WHERE and HAVING?

WHERE is used to filter records before any groupings are made. HAVING is used to filter records after the GROUP BY clause has been applied to aggregate data.

9. What is a Unique Constraint?

A Unique Constraint ensures that all values in a column are different. Unlike a Primary Key, a column with a Unique Constraint can accept one NULL value.

10. What are Aggregate Functions?

Aggregate functions perform a calculation on a set of values and return a single value. Common examples include SUM(), AVG(), COUNT(), MIN(), and MAX().
